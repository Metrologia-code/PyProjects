devices_logger.py — логирование данных с приборов

Назначение

Программа периодически опрашивает измерительные приборы и записывает их показания в файл, а при необходимости строит графики в реальном времени. Запускать программу нужно из корня проекта.

Описание устройств (ключ -d)

Ключ -d определяет, какие приборы участвуют в измерении, какие пресеты к ним применяются, какие величины записываются в файл и что выводится на графики. Синтаксис:

    <имя_прибора>[.ch<номер>][~<пресет>]=<величины>[;ch<номер>[~<пресет>]=<величины>...] [<имя_прибора>...]

Каждая величина записывается как <величина>[@<имя_полотна>]. Если имя полотна не указано, величина попадает только в файл и на график не выводится.

Символы означают следующее:

    пробел              — разделяет устройства;
    точка (.)           — начинается перечень каналов;
    ch<номер>           — номер канала;
    тильда (~)          — имя пресета настроек;
    знак равно (=)      — начинается перечень измеряемых величин;
    запятая (,)         — разделяет величины;
    символ @ (собака)   — имя полотна, на которое попадёт величина;
    точка с запятой (;) — разделяет каналы одного прибора.

Если тильду не указывать, прибор запускается без настройки.

Пример:

    python devices_logger.py -d "TH1992B_1.ch1~APL_I=CURR,VOLT@ток;ch2~APL_I=CURR@ток" TH2690A_1~FDUK=CURR@ток -n 300 -cp 200 -fs

Остальные ключи

    -fs, --faststart    — запуск без предварительной настройки приборов.
    -pl, --plot         — габариты окна и полотен в формате key=value: width, height (размер окна), canvas_height (высота полотна), n_cols (число колонок). Пример: -pl width=12 height=6 canvas_height=2.5. Неизвестный ключ или некорректное значение приводят к ошибке и остановке программы.
    -np, --noplot       — не создавать графики, даже если в -d указаны метки @.
    -ho, --hold         — не закрывать окно графика по завершении программы.
    -p, --period        — период одного шага измерения в секундах (по умолчанию 1.0).
    -f, --filename      — имя файла результатов. Если не указано, имя генерируется как logger_<гггг>-<мм>-<дд>_<чч>-<мм>-<сс>.
    -n, --points        — количество измерений (по умолчанию 999999).
    -cp, --canvaspoints — количество точек по оси X на графике (по умолчанию 3600).

Формат оси Y

Тики оси Y всегда выводятся с тремя знаками после запятой и физической приставкой СИ: -90.000 pA, 1.234 mA, 4.560 MOhm. Научной нотации и множителя вида 1eN над осью нет. Подпись оси — это имя кривой (например, TH1992B_1.ch1=CURR).

axes_scanner.py — автоматизация серии экспериментов сканирования щелью

Назначение

Программа читает файл заданий, перемещает ножи через контроллер движения и снимает показания приборов в каждой позиции. Запускать программу нужно из корня проекта.

Описание устройств (ключ -d)

Синтаксис и правила те же, что и в логгере:

    <имя_прибора>[.ch<номер>][~<пресет>]=<величины>[;ch<номер>[~<пресет>]=<величины>...] [<имя_прибора>...]

Каждая величина записывается как <величина>[@<имя_полотна>]. Если имя полотна не указано, величина попадает только в файл и на график не выводится.

Пример:

    python axes_scanner.py -d "TH1992B_1.ch1~FDUCK_I=CURR,RES@scan;ch2~APL_I=CURR@scan" TH2690A_1~PICOAMMETER_TEST_1=CURR@scan -tf EXP2_APL+APT.txt

Остальные ключи

    -r, --run         — индексы экспериментов для запуска (например, -r 0 2 3). Если ключ не указан, запускаются все эксперименты из файла.
    -tf, --taskfile   — путь к файлу заданий (по умолчанию Axes_scan_default.txt).
    -fs, --faststart  — запуск без предварительной настройки приборов.
    -pl, --plot       — габариты окна и полотен (те же ключи, что и в логгере; формат оси Y описан в разделе про логгер).
    -np, --noplot     — не создавать графики, даже если в -d указаны метки @.
    -ho, --hold       — не закрывать окно графика по завершении программы.
    -sf, --singlefile — сохранять результаты всех экспериментов в один файл.
    -x, --xaxis       — ось X графика по умолчанию (time или имя оси). Задание может переопределить её столбцом x_axis.

Файл заданий

Файл заданий — это таблица с разделителем-табуляцией. Первая непустая строка является заголовком и содержит имена столбцов, поэтому порядок столбцов может быть любым, а новые столбцы можно добавлять в середину и в конец. Строки, начинающиеся с символа #, считаются комментариями.

Обязательные столбцы: APT, APL, APR, APB (значение оси задаётся как start:end или одним числом) и intvls (число интервалов).

Необязательные столбцы: post_delay (пауза после выхода в позицию, по умолчанию 0.0), filename (имя файла результатов), x_axis (ось X для графиков этого задания: time или имя оси).

Если столбец x_axis заполнен, он переопределяет глобальный ключ -x для этого задания.

Незнакомые столбцы не мешают работе: о них выводится предупреждение, и они пропускаются. Ошибки в данных (например, отсутствует обязательная ось, не указано число интервалов или задана неизвестная ось X) приводят к сообщению с номером строки и остановке программы.

Пример файла заданий:

    #APT	APL	APR	APB	intvls	post_delay	filename	x_axis
    10:20	20	20	20	15	0.5	test_file_1.txt	APT #здесь можно комментарий написать
    10:25	25	25	25	15	0.1	test_file_2.txt	APT

Если имя файла результатов в задании не указано, оно генерируется в формате <имя_файла_задания>_<гггг>-<мм>-<дд>_<чч>-<мм>-<сс>.

Конфигурация TH1992B

#Режим работы источника
#VOLT, CURR
Mode = VOLT
#Режим сигнала источника
#FIX (DC), SWE (SWEep), LIST (по точкам)
AWG = FIX
#Диапазон сигнала источника напр./тока
#для VOLT - 0.2, 2, 20, 200 (V)
#для CURR - 10e-9, 100e-9, 1e-6, 10e-6... 1, 1.5, 3 (A)
SOURCE-range = 200
#Режим автоматического переключения диапазонов измерения
#ON, OFF
SENSE-range auto = OFF
#Диапазон измерения
#для VOLT - 0.2, 2, 20, 200 (V)
#для CURR - 10e-9, 100e-9, 1e-6, 10e-6... 1, 1.5, 3 (A)
SENSE-range = 10e-06
#Лимит измерения напр./тока (V или A)
SENSE Limit = 100e-03
#Значение сигнала напр./тока источника (V или A)
SOURCE-value = -24
#Способ отключения канала
#ZERO, HIZ, NORM
Off state = HIZ
#Значение апертуры измерения
#это время, за которое производится усреднение (s)
Aperture = 0.02
#Режим заземления клеммы Low
#GRO (GROund, замыкание на корпус), FLO (FLOat, не заземлено)
Low T = GRO
#Overvoltage/overcurrent protection
#1, 0
OVP/OCP = 0
#Вкл/выкл фильтра выходного сигнала
#1, 0
Filter = 1
#Time constant of output filter (s)
#LPF-t = 5e-6
#High capacitance mode
#1, 0
High C = 0
#Remote function (4-wire)
#1 (используется схема подключения 4-wire), 0 (2-wire)
Sensing = 0

Конфигурация TH2690A

# Режим прибора
# RES|VOLT|CURR
Func = CURR

# Диапазон измерения
# CURR: 1 - Auto; 2 - 20mA; 3 - 2mA; 4 - 200uA; 5 - 20uA; 6 - 2uA; 7 - 200nA; 8 - 20nA; 9 - 2nA; 10 - 200pA; 11 - 20pA
# RES:  1 - Auto; 2 - 100TΩ; 3 - 10TΩ; 4 - 1TGΩ; 5 - 100GΩ; 6 - 10GΩ; 7 - 1GΩ; 8 - 100MΩ; 9 - 10MΩ; 10 - 1MΩ; 11 - Manual
# VOLT: 1 - Auto; 2 - 2V; 3 - 20V
Range = 5

# Скорость измерения

# Страница дисплея, необходимо быть на ней для измерения
# MEAS
DisplayPage = MEAS

# Включение/выключение амперметра
# ON|OFF
AmmeterSwitch = ON

# Установка напряжения
# значение в вольтах
#SourceValue = 0

# Включение/выключение источника
# ON|OFF
#SourceSwitch = ON
