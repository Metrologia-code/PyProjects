1. Формат аргумента -d, --devices:

    Аргумент -d определяет, какие измерители используются в эксперименте, как их использовать (с настройками или без), какие величины записывать в файл и выводить на графики.

    <имя_измерителя>[.ch<номер>][~<пресет>]=<величины>[;ch<номер>[~<пресет>]=<величины>...] [<имя_измерителя>...]

    Каждая <величина>:
        <измеряемая_величина>[@<имя_графика>]

    Каждое имя устройства может быть указано не более одного раза. Для устройства, имеющего каналы, указание канала обязательно. Каждый канал может быть указан только один раз в одном устройстве. Не указанные каналы не используются. В пределах одного устройства или канала каждая измеряемая величина может быть указана только один раз.

    Пробел разделяет разные устройства.
    Точка начинает перечень каналов устройства, после точки указывается канал в формате ch<номер>. Если у устройства нет каналов - точка не ставится и канал не указывается.
    ; разделяет каналы одного устройства.
    = отделяет перечень измеряемых величин от номера канала (или от имени устройства, если у устройства нет каналов).
    , разделяет измеряемые величины в одном наборе.
    @ отделяет имя графика от измеряемой величины. Если имя графика не указано, величина на график не выводится.
    ~ отделяет имя пресета настроек от номера канала (или от имени устройства, если у устройства нет каналов). Если пресет не указан - настройки не применяются.

    Пример:
        -d TH1992B_1.ch1~TEST_VOLT=CURR,VOLT@p1;ch2=CURR@p1 TH2690A~PRESET_1=CURR@p2,VOLT
        Этот аргумент означает: используются два устройства — TH1992B_1 (два канала) и TH2690A (без каналов). У TH1992B_1 на канал ch1 применён пресет TEST_VOLT, с него снимаются ток (без графика) и напряжение (на график p1); на канал ch2 пресет не применён, с него снимается ток на график p1. У TH2690A применён пресет PRESET_1, с него снимаются ток (выводится на график p2) и напряжение (без графика).
        

2. Описание устройств

    Файл Devices.ini содержит описание всех имеющихся устройств. Раздел default отсутствует. Наименования разделов являются именами устройств. Значения, являющиеся перечнями (например: channels = 1,2), имеют разделитель - запятую.
    Разделы могут содержать следующие поля (а также любые другие по необходимости):
        
        type       — instrument | controller
        model      — модель устройства, одновременно имя файла библиотеки
        interface  — тип связи: tcpip | usbtcm | serial | ...
        address    — IP-адрес и порт (для tcpip)
        channels   — перечень каналов, если есть (для instrument)
        values     — измеряемые величины, которые можно запрашивать у устройства (для instrument)
        axes       — перечень осей (для controller)
        axesnames  — имена осей (для controller)
        units      — единицы измерения устройства (для измерителя — по одной единице на величину в порядке values, для контроллера — одна общая единица для всех осей)
    
    Примеры:

        [TH1992B_1]
        type = instrument
        model = th1992b
        interface = tcpip
        address = 192.168.88.11:45454
        channels = 1,2
        values = VOLT,CURR,RES
        units = V,A,Ohm

        [TH2690A_1]
        type = instrument
        model = th2690a
        interface = tcpip
        address = 192.168.88.12:45454
        values = VOLT,CURR
        units = V,A


3. Файлы результатов

    Файл результатов измерений имеет расширение txt, и построчно хранит данные, разделенные табуляцией. Первой строкой всегда является заголовок. Именем файла считается имя файла без расширения. Дополнительные файлы с другими расширениями, например - изображения с графиками, наследуют имя файла. Если при создании файла в директории уже существует файл с таким именем, то к имени файла добавляется '(<индекс>)', начиная с единицы. При помощи аргументов можно выбрать другой путь сохранения файлов. Если имя файла результатов не указано, то оно генерируется в формате <режим>_<гггг>-<мм>-<дд>_<чч>-<мм>-<сс>. Перед началом выполнения цикла режима работы выводится информация об имени файла результатов (или файлов) с указанием директории.
    
    Запись метаданных в файл результатов не предусмотрена. В каждом режиме работы может быть своя система отсчета времени. В файл записывается время, которое отсчитано от фиксированного момента времени (например, начала выполнения цикла программы).
    
    В axes_scanner после столбца времени в файл результатов записываются столбцы положений осей - координат, в которые оси фактически прибыли (значения, возвращённые контроллером). Заголовок столбца - <имя_оси> pos, <единица>. Столбцы положений осей располагаются перед столбцами измеряемых величин.
    
    Примеры первых двух строк:
